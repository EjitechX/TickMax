EA format guide

Define OnTick() (required), optionally OnInit() and OnDeinit(). It runs once per new bar. Shift 1 is the last closed bar; shift 0 is the current price.
Inputs: add // @input name = value lines (numbers, true/false or text) and read them as Inputs.name. Name it with // @name My EA.
Data: Open/High/Low/Close/Time(shift), Bars(), Pip(), Point().
Indicators (MT5 formulas): iMA(period,"SMA"|"EMA"|"SMMA"|"LWMA",shift), iRSI(period,shift), iATR(period,shift), iMACD(fast,slow,signal,shift) → main/signal/hist, iBands(period,dev,shift) → upper/middle/lower, iStochastic(k,d,slowing,shift) → k/d, HighestHigh(period,shift), LowestLow(period,shift).
Trading: Buy(lots,sl,tp), Sell(lots,sl,tp), Positions(), PositionsTotal(), PositionClose(id), CloseAll(), PositionModify(id,sl,tp), AccountBalance(), AccountEquity(), Ask(), Bid(), Print().
